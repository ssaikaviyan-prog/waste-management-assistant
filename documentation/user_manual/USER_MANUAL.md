# User Manual

## Opening the Website

Open <https://wastemanage-edf9jmvs.manus.space> in a modern browser. The dashboard provides entry points to the assistant, classifier, report form, guide, and about pages.

## Asking the AI Assistant

Select **Ask AI Assistant** or open **AI Assistant** from the navigation. Type a question about segregation, recycling, composting, hazardous waste, e-waste, waste reduction, collection guidance, or general waste management. Suggested questions can be selected to start a conversation. The interface shows loading and error states when the server-side AI is processing or unavailable.

## Scanning Waste

Open **Classify Waste**. Select **Browse files**, use the camera on a supported device, or drag an image into the upload panel. Review the preview, then select the native AI classification action. The result panel displays the detected category, confidence, recommended disposal method, and recycling recommendation.

## Reporting a Waste Issue

Select **Report Waste Issue** on the homepage or open **Report Waste**. Choose a category, enter a location, optionally use browser location detection, attach a photo, describe the issue, and optionally provide a name and contact detail. Submit the form to receive a generated report ID and the initial **Pending Review** status.

## Reading the Waste Guide

Open **Waste Guide** and use the search and category controls to find practical guidance about segregation, recycling, composting, e-waste, plastic waste, household waste, and sustainable practices.

## Safe Use

Do not treat the application as a replacement for local authority instructions. For hazardous, chemical, medical, battery, or unknown materials, follow approved specialist guidance and avoid unsafe handling.
